# Cypress Automation Tests for Automation Test Store

This repository contains automated UI tests for the educational e-commerce platform Automation Test Store (https://automationteststore.com/).

##Tech Stack
* **Framework: Cypress
* **Language: JavaScript

##Test Scope
*User registration flow (Registration form validation)
*User authentication flow (Login and input validation)

##How to Run Tests Locally
1. **Clone the repository:
```bash
git clone https://github.com/shlikalexandra/cypress.js
```
2. **Navigate to the project directory:
```bash
cd cypress.js
```
3. **Install dependencies:
```bash
npm install
```
4. **Open Cypress Test Runner (Interactive Mode):
```bash
npx cypress open
```
